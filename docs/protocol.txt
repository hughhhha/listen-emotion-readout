Protocol 1.0 — fixed before evaluating model predictions
Model order: Qwen2.5-Omni-7B first (published reference). Evaluate Qwen2.5-Omni-3B only after the primary 7B gain is verified to exceed 3 absolute percentage points on the seven-condition mean; target stretch 5 points. No simultaneous model inference. GPU 0 only.
Official dataset: VibeCheck1/LISTEN_full, f6397b5bfedd85ae41b80dac13e95bb55adf0a35. Reference code: DeliJingyiC/LISTEN 32966584488bd3b3c67a150bd55f1f18ca09ef76. Use all runnable native author train rows in ten ordered conditions for baseline. Compare against the paper and report limitations where current labels or letter space differ.
Frozen model features: original generated option (baseline), first-token letter logits, mean pooled frozen audio tower representation. Labels, source, speaker IDs, filename, and ground truth do not enter the prompts or features.
Heldout evaluation: preserve native test rows for six audio-bearing conditions. Native test lacks paralinguistic items; hold out first ceil(20% * available type4 groups) sorted by sha256('LISTEN-type4-v1:42:<group>'). Group same 16-kHz PCM or same canonical source+recording ID across question types; remove all overlapping groups from development. Report native six separately and combined seven (equal weight per condition, primary), plus item-level pooled accuracy. Text-only tasks are controls.
Three waveform summaries: pitch span (P90–P10 in semitones on confidently periodic frames), loudness span (P90–P10 dB on active frames), within-utterance pause fraction. Two fixed candidate representations: these three alone or concatenated with 64 train-fold-only PCA components of the frozen audio encoder. Standardized multinomial logistic regression, C=1. Calibrate fixed Qwen option scores with a global temperature and class biases on training data. Blend probabilities with weight in {0,0.1,...,1}. Select representation and blend weight using only grouped three-fold development predictions, maximize unweighted seven-condition mean accuracy. Ties favor the simpler representation, then lower acoustic weight. No held-out results used in selection.
Controls: scored generative Qwen, first-letter logits argmax, calibrated logits, acoustic-only readout, fusion. 2,000 paired, recording-group bootstrap draws for the predeclared aggregate difference. Report both wins and regressions. Actor-disjoint diagnostics are a separate evaluation.
